## Inter ExtraBold (3D lettering)

`inter_extrabold.typeface.json` is [Inter](https://rsms.me/inter/) 4.1 ExtraBold by Rasmus Andersson and the Inter
Project Authors, licensed under the SIL Open Font License 1.1 ([`INTER_LICENSE.txt`](INTER_LICENSE.txt)).

It was converted to three.js typeface JSON (Latin, Latin-1, Latin Extended-A and punctuation only) with
[`scripts/make-typeface.mjs`](../../../../scripts/make-typeface.mjs) from `extras/ttf/Inter-ExtraBold.ttf` in the
official release zip. Text in other scripts is drawn with the system font instead.
